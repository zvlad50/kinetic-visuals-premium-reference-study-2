# Собственные материалы проектов

Сейчас фото, видео и последовательности кадров не подключены. Этот файл не является медиаматериалом.

Сохраните действующие публичные пути; не переносите файлы в другую структуру без обновления ссылок и повторной проверки.

```text
cases/
  kvartira/
    preview.mp4
    before.webp
    after.mp4
    frames/0001.webp ... NNNN.webp
  loft/      # такие же имена
  dom/       # такие же имена
```

- Только собственные материалы или файлы с подтверждёнными правами; запишите источник, правообладателя и условия использования рядом с исходниками.
- `before.webp`: исходное фото/визуализация и постер. `preview.mp4`: короткий беззвучный клип. `after.mp4`: оживлённая версия. MP4 с H.264, без аудиодорожки, `faststart`; WebP для кадров с одинаковыми размерами и последовательной нумерацией от 0001 без пропусков.
- Мастер-файлы и черновые версии храните вне публичной папки: всё в public доступно по URL, даже если robots запрещает индексацию.
- Для сценарных монтажных сцен: `kvartira_s01_v01_16x9.mp4`, `kvartira_s01_v01_9x16.mp4`; аналогично `loft` и `dom`. Финальные файлы для сайта переименуйте в ожидаемые выше имена.
- Вертикальные версии не подключаются автоматически: текущий реестр не содержит отдельных мобильных путей. Не заменяйте один формат другим без просмотра обрезки.
- `frameCount` увеличивать только до числа фактически подготовленных последовательных кадров. На узком экране выбирается каждый второй, но первый и последний всегда нужны.
- После добавления файлов перезапустите локальное чтение конфигурации/пересоберите сайт: список доступных локальных медиа формируется при запуске Vite и сборке. Проверка MIME остаётся обязательной.
- Перед будущей публикацией проверьте лицензии, декодирование, постер, сравнение, тур, reduced motion и mobile; текущий QA не подтверждает воспроизведение отсутствующих файлов.
