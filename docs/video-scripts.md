## Общие требования

- 16:9: горизонтальная композиция для сайта; сохранять читаемую планировку, не использовать широкоугольные искажения. 9:16: отдельное кадрирование/движение с центральной свободной осью; не слепая обрезка широкого кадра. Предлагаемые мастеры 1920×1080 / 1080×1920, единый frame rate 24 или 25 fps — параметры производства, не готовых файлов.
- Без текстов, логотипов, водяных знаков в сгенерированном/исходном видеоряде. Титры необязательны; если нужны, добавить отдельно при монтаже только существующее название кейса. Никаких цен, адресов, awards, площади или клиентов.
- Негативные ограничения: без искажённой архитектуры, «плавающих» стен, морфинга мебели, лишних дверей/окон, неверных отражений, мерцания света, camera shake, speed ramp, людей и случайных предметов. Не дорисовывать неизвестные помещения.
- Первый и последний кадр каждой сцены пригодны для спокойного стыка; не использовать агрессивные переходы. Цвет и экспозиция согласованы, акцент на проверяемых формах и материалах.
- Для сайта: беззвучные preview/after MP4 H.264, faststart; постер WebP и последовательные WebP frames отдельно. Финальная нумерация — `0001.webp`…`NNNN.webp`, без пропусков. До подготовки файлов `frameCount` остаётся 0.
- Хранить исходники и сведения о правах вне public; публиковать только разрешённые финальные варианты. Каждый сценарий можно заменить, не меняя route URL или slug.
