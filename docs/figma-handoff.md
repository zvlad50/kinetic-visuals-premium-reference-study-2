## Переменные, стили и привязки

- Коллекция `Kinetic / Colors` — 6 переменных: `background`, `surface`, `divider`, `text-primary`, `text-secondary`, `bronze`.
- Коллекция `Kinetic / Spacing` — 6 значений: 8 / 16 / 24 / 32 / 48 / 64.
- 6 локальных текстовых стилей: `Display/Hero`, `Display/Section`, `Display/Card`, `UI/Body`, `UI/Label`, `UI/Action`.
- 23 ключевых заполнения бордов и компонентов привязаны к переменным цвета.

Соответствие переменных цвета и токенов CSS (`src/styles.css`):

| Переменная Figma | Токен CSS | Документированный hex |
|---|---|---|
| `background` | `--background` | `#12100E` |
| `surface` | `--surface` | `#1B1815` |
| `divider` | `--line` | `#322C26` |
| `text-primary` | `--foreground` | `#EFE8DC` |
| `text-secondary` | `--muted-foreground` | `#A89F92` |
| `bronze` | `--primary` | `#D4A35A` |

В CSS цвета записаны в формате `oklch`; hex в таблице — документированные исходные значения палитры, а не результат извлечения из кода.

## Статус токенов — читать осторожно

- Значения Figma — **предложенные** величины для передачи дизайна. Это не доказательство того, что все spacing-токены Figma реализованы в коде как переменные: с 18.10.2026 в CSS есть `--space-1…6` (8–64 px), но интервалы в разметке пока заданы утилитарными классами.
- Фактическая типографика проекта подтверждена CSS: **Cormorant Garamond** для display-заголовков и **Montserrat** для интерфейса и основного текста. Текстовые стили Figma — предложение, а не описание текущего кода.
- Корректные hex-значения основаны на документированной визуальной палитре.
