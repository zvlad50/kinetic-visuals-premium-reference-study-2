## Точная правка

В `head().meta` файла `src/routes/__root.tsx` добавлено:

```tsx
{ name: "robots", content: "noindex,nofollow" },
```

Ожидаемый HTML на страницах, наследующих корневой запрет:

```html
<meta name="robots" content="noindex,nofollow">
```

Существующие `noindex, nofollow` у кейсов и туров сохранены; пробел после запятой не меняет смысл директив.

Полное итоговое содержимое `public/robots.txt`:

```text
User-agent: Googlebot
Disallow: /

User-agent: Bingbot
Disallow: /

User-agent: Twitterbot
Disallow: /

User-agent: facebookexternalhit
Disallow: /

User-agent: *
Disallow: /
```

Существующие отдельные группы сохранены и тоже полностью заблокированы. Нет разрешающих `Allow` и директивы `Sitemap`.
