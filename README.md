# Kinetic Visuals Studio

Создай сайт-портфолио (витрину) с закрытыми от поисковиков страницами кейсов. Язык интерфейса: русский. Используй стандартный стек Lovable. Не добавляй бэкенд, регистрацию и формы: контакты сделай кнопками-ссылками.

СТИЛЬ
Тёмный, кинематографичный. Цвета: фон #12100e, поверхность #1b1815, линии #322c26, основной текст #efe8dc, приглушённый текст #a89f92, акцент #d4a35a (текст на акценте #12100e). Шрифты Google Fonts: Cormorant Garamond (500, 600) для заголовков, Manrope (400, 500, 600) для текста, кириллица обязательна. Без градиентных подложек и эмодзи, без шрифтов Inter, Roboto и Arial. Кнопки высотой не менее 44 px, контраст текста не ниже 4.5:1.

СТРАНИЦЫ
1) «/»: витрина.
- Шапка: слева «[ИМЯ СТУДИИ]», справа ссылки-якоря «Кейсы», «Как это работает», «Услуги», «Контакты» и кнопка «Написать в Telegram».
- Первый экран: подпись «Анимированные сайты для интерьеров и недвижимости», заголовок «Фотографии, по которым можно пройти», абзац «Превращаю фото и визуализации интерьеров в сайты, где камера движется вместе с прокруткой колёсика.», кнопки «Смотреть кейсы» и «Как это работает». Справа блок 640×480 под короткий зацикленный видеоклип (пока заглушка).
- «Кейсы»: сетка из трёх карточек, данные берутся из реестра. В карточке: превью-клип (заглушка), тип, название, описание, строка приёмов, метка статуса, «Открыть кейс →».
- «Как это работает»: четыре шага: 01 Фото или планировка, 02 Ключевые кадры, 03 Оживление, 04 Сайт, с короткими описаниями.
- «Услуги»: три карточки: «Оживление фото», «Сайт с проходом по объекту», «Шаблон для агентства». В каждой «Стоимость: [ЦЕНА]», «Срок: [СРОК]» и кнопка «Обсудить».
- «Контакты»: заголовок «Расскажите про ваш объект», кнопки «Написать в Telegram» и «Написать в WhatsApp», подпись «[@ВАШ_НИК] · [НОМЕР]».
- Подвал: «Демонстрационные проекты созданы на собственных или сгенерированных материалах. Оживлённые фотографии помечаются как визуализация.»

2) «/cases/:slug»: страница кейса, один общий шаблон, данные из реестра. Кнопка «← Вернуться в портфолио»; метка типа и «Демонстрационный проект»; заголовок и описание; переключатель «Исходное фото» / «Оживлённое» над блоком 1248×560 (для оживлённого видео с кнопкой воспроизведения, для исходного фото; пока заглушки); блок «Что применено» (проход по объекту, оживлённые комнаты, единый свет и стиль) и блок «О проекте» (тип объекта, материалы, срок, статус); кнопки «Открыть сайт-кейс →» и «Заказать такой же» (ведёт в блок контактов витрины).

3) «/cases/:slug/tour»: сцена прохода. Сейчас создай маршрут-заглушку: полноэкранный тёмный экран, название комнаты и вертикальная рейка из пяти комнат (Вход, Гостиная, Кухня, Спальня, Терраса), клик по которой переключает заглушки. Полную версию сделаем следующим шагом.

РЕЕСТР КЕЙСОВ
Создай файл src/data/cases.ts как единственный источник данных. Поля: slug (латиницей), tag, title, text, meta, status, previewVideo, beforeImage, afterVideo, frameCount (пока 0), rooms (5 штук, у каждой name). Три записи: «kvartira» (Квартира, «Квартира в новостройке»), «loft» (Дизайн интерьера, «Лофт-студия дизайнера»), «dom» (Загородный дом, «Загородный дом»). Тексты придумай коротко в том же духе, статус «Демонстрационный проект». Витрина, страница кейса и сцена только читают этот файл. Добавление нового кейса должно сводиться к одной новой записи и файлам в public/cases/<slug>/.

МЕДИА
Пока файлов нет, показывай аккуратные тёмные заглушки с подписью. Позже файлы будут лежать в public/cases/<slug>/ (preview.mp4, before.webp, after.mp4, frames/0001.webp и далее). Видео без звука, с preload="none" и постером, подгружай медиа только когда блок попадает в экран.

ЗАКРЫТИЕ ОТ ПОИСКОВИКОВ
На страницах /cases/* добавь <meta name="robots" content="noindex, nofollow">, в robots.txt запрети /cases/, не включай кейсы в sitemap. В адресах только латиница.

ПРОЧЕЕ
Адаптивная вёрстка (проверь на ширине 390 px), настоящие кнопки и ссылки, aria-label у иконок, alt у изображений. Не выдумывай цифры, отзывы и логотипы: недостающее оставляй в квадратных скобках.
